# Безопасный пример

`autoruns-demo.csv` — синтетическая строка для проверки импорта. Она указывает на штатный Блокнот Windows и НЕ утверждает, что Блокнот прописан в автозапуске. Никакие записи автозапуска этот файл не создаёт.

В приложении: «Импорт Autoruns» → выбрать этот CSV → «Проверить». Блокнот не запускается: читаются его байты и цифровая подпись. Для ИИ перейдите на вкладку «Объяснение Codex» и сначала просмотрите отправляемые данные.

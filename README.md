# Autoruns Lens — prototype 0.1

Локальный Windows-инструмент для разбора записей Autoruns и статического анализа файлов.

После локальной debug-сборки EXE находится в `src-tauri/target/debug/autoruns-lens.exe`. Его можно запустить без dev-сервера. Текущий прототип использует установленный Python 3 для аналитического движка; самодостаточный sidecar и установщик запланированы для следующих версий. Результаты проверок и ограничения описаны в `VERIFICATION.md`.

## Запуск

Нужны Node.js 22+, Python 3.10+, Rust 1.90 и Microsoft C++ Build Tools (для Tauri). Версия Rust зафиксирована только для проекта в rust-toolchain.toml.

```powershell
npm install
npm run desktop
```

Можно также открыть `Start-Lens.cmd` после установки зависимостей.

Для первой проверки импортируйте `examples/autoruns-demo.csv`: это явно обозначенная демонстрационная строка со штатным Блокнотом, а не результат сканирования вашего автозапуска.

Интерфейс отдельно: `npm run dev` (браузер не имеет доступа к движку).
Проверки: `npm run test:engine`, `npm run build`, `cargo check --manifest-path src-tauri/Cargo.toml`.

## Уже реализовано

- Импорт CSV Autorunsc, UTF-8 / UTF-16 / CP1251; поиск по записям.
- Выбор локального файла, SHA-256, Authenticode, минимальные PE-метаданные, выбранные ASCII-строки.
- Признаки системных загрузчиков и кодированных команд. Полезная нагрузка DLL/скрипта не разрешается автоматически: её нужно проверить отдельно.
- Опциональные CLI-адаптеры capa, FLOSS, Detect It Easy; инструменты должны быть установлены отдельно и находиться в PATH.
- Локальная SQLite-история, JSON-экспорт, честные статусы пропущенных и неуспешных проверок.
- Codex CLI через ChatGPT-подписку: предварительный просмотр данных, структурированный ответ, проверка ссылок на доказательства.

## Codex

Установите официальный Codex CLI и выполните `codex login`, выбрав ChatGPT. Приложение проверяет `codex login status`; API-авторизация не допускается для объяснений. Переменные `CODEX_API_KEY` и `OPENAI_API_KEY` исключаются из окружения дочернего процесса. Пользовательская конфигурация Codex не загружается. Запуск: `codex exec`, read-only sandbox, approval_policy=never, shell tool выключен, ephemeral session, строгая схема ответа. Используется модель по умолчанию CLI. Лимиты общие с вашим аккаунтом; автоматического перехода на API нет.

В OpenAI передаётся только показанный перед отправкой JSON. Он может содержать чувствительные строки, имена и результаты внешних анализаторов; исходные байты файла не отправляются. Удаление некоторых путей не является полной анонимизацией.

## Границы прототипа

Не антивирус и не изолированная песочница. Файлы не запускаются и автозапуск не меняется. Статические парсеры работают на хосте; вредоносные образцы лучше исследовать в отдельной VM. Отдельный процесс сам по себе не защищает от уязвимостей парсера. Автоматический запуск Autorunsc, YARA-X с правилами, VirusTotal, Ghidra, Claude, отмена выполняющейся задачи и установщик пока не реализованы. Проверки внешними CLI отключены по умолчанию. Статический результат всегда помечен как неполный.

Лимиты: файл 128 МБ, CSV 16 МБ / 10 000 записей, строки из первых 16 МБ, 40 строк в отчёте, 90 секунд на внешний анализатор, 180 секунд на Codex (плюс время завершения процессов). Результат анализатора больше 4 МБ не засчитывается. Внешние результаты для ИИ обрезаются до 12 000 символов на инструмент с явной отметкой. Анализаторы получают копию хэшированных байтов в чистой временной папке, без соседних файлов. База: Windows LocalAppData/local.autoruns.lens/lens.db (путь определяется Tauri).

## CLI движка

Из корня проекта:
```powershell
'{"action":"status"}' | python engine/cli.py --data-dir work/data
```
Один JSON-запрос на stdin, один JSON-ответ на stdout. Действия: status, import, analyze, history, preview_ai, explain. Движок использует только стандартную библиотеку Python.

## Структура

`src/` — React, `src-tauri/` — Rust IPC, `engine/` — Python-анализ и Codex, `tests/` — безопасные тесты. Код проекта не сканирует компьютер автоматически.
